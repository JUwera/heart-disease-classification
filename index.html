💗 Heart Disease Risk Predictor

This interactive prototype estimates heart disease risk from patient health information using a Random Forest machine learning model trained on the UCI Heart Disease dataset.

This tool is for educational and research purposes only. It does not provide a medical diagnosis and should not replace professional clinical advice.

About this prototype

The application demonstrates how a trained machine learning model can be integrated into a users software tool. It includes data preprocessing, model inference, input validation and a simple explanation to improve transparency.

System Design Notes

This prototype includes a complete mini-pipeline: data loading, missing-value handling, categorical encoding, feature scaling, model inference and output presentation.

The interface was designed to prioritise usability, clarity and responsible communication of risk information without harm.

Feature importance values indicate the relative influence within the trained Random Forest model and do not imply medical causation.
